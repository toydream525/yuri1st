# yuri1st 全功能说明

版本：0.4.0（2026-08-11）

## 1. 百合目录

### 分类浏览

- 动画（Bangumi type 2）
- 漫画（type 1 + `漫画` 元标签）
- 轻小说（type 1 + `小说` 元标签）
- 游戏（type 4）

四个分类独立同步、独立筛选。目录来自 Bangumi 上带有精确 `百合` / `轻百合` 用户标签的条目，客户端会再次校验标签，避免把无关条目收进来。

### 三态排版布局

- 列表模式：封面 + 标题 + 评分/人数/排名 + 标签 + 操作按钮
- 两列封面：每行两个封面，标题与评分显示在封面下方
- 四列密集：每行四个封面，适合快速浏览更多条目
- 左上角排版按钮循环切换三种布局，并显示下一种布局对应图标

### 数据同步

- 首次打开自动拉取目录，显示逐页进度
- 内置基础条目，首次打开可离线浏览
- 普通刷新：只累加本地没有的新条目，不覆盖已有数据
- 强制刷新（设置中）：重新拉取全部命中条目，本地收藏/屏蔽/标记保留
- 超长标签分区自动按年份分片同步，进度会标明年份区间
- 自动刷新窗口约 12 小时

## 2. 搜索与筛选

### 本地搜索

左上角搜索按钮打开，实时匹配：日文名、中文名、英文名、平台、标签、原作/Staff 等基本资料。输入文字后搜索按钮会高亮。

### 在线搜索与导入

支持：

- 输入关键词在线搜索并导入（只收录含百合/轻百合标签的条目）
- 粘贴 bgm.tv / bangumi.tv 条目链接或纯 ID 直接导入

### 高级筛选

- 分类：不限 / TV 动画 / OVA / 剧场版 / 其他
- AI/自定义：不限 / 真百 / 轻百 / 非百 / 赢面 / 输面
- 最低评分人数：不限 / 10+ / 50+ / 200+
- 年份
- 仅收藏
- 仅 NSFW（需先开启 NSFW）
- 反选：在搜索、收藏、NSFW 等基础约束内，对分类、年份、评分人数、AI/自定义等高级条件筛出的结果反选，方便快速排除或定位条目

### 分页

- 每页固定 20 条
- 上一页 / 下一页，页码胶囊可点击输入页码直接跳转

## 3. 条目详情

- 封面、标题（中文名/原名）、类型、日期、章节数、评分、评分人数、排名
- 1～10 分评分分布
- 收藏统计（想看/看过/在看/搁置/抛弃人数）
- 简介、基本资料、标签
- 打开 Bangumi 官方原页面
- 收藏 / 屏蔽（图标按钮）
- 自定义赢面 / 输面标记
- Bangumi 点格子
- AI 百合倾向分析

## 4. 收藏 / 屏蔽 / 自定义标记

### 本地收藏

不需要 Bangumi 账号，列表和详情页都可操作；可配合“仅收藏”筛选。

### 屏蔽

- 列表卡片屏蔽按钮，屏蔽前有确认弹窗
- 屏蔽后从列表和随机推荐中隐藏
- “设置 → 屏蔽管理”可查看、解除、彻底删除

### 屏蔽词

- 按名称、别名、标签、基本资料文字过滤
- “设置 → 屏蔽词”管理

### 赢面 / 输面

- 每个条目可标记“赢面”或“输面”，再点一次取消
- 列表卡片右侧竖排按钮，选中高亮；详情页也有
- 高级筛选里可按赢面 / 输面过滤

## 5. AI 百合倾向分析（高级功能）

### 能力

- 判断真百 / 轻百 / 非百倾向，附置信度
- 输出判断理由与提示信息；男性配角、BE 或配角含男性角色本身不会被作为判断依据
- 默认扩大真百 / 轻百范围：带恋爱标签的作品更倾向真百；百合结局默认真百；仅当男性主要角色和 BG 要素占较大比重，或结局为 BG 时判为非百
- 参考来源，并明确标注“仅供参考”

### 配置

“设置 → 高级功能 → AI 百合倾向分析”：

- 接口地址：默认 `https://api.openai.com/v1`，兼容 DeepSeek、Moonshot、自建端点等标准 OpenAI 兼容接口
- API Key：Android Keystore 加密保存，可留空保持不变或一键移除
- 模型名称：默认 `gpt-4o-mini`
- 联网搜索：仅 OpenAI 官方端点启用 `web_search` 工具；其他端点使用模型自身知识
- 判断偏好：用自然语言调整 AI 的判断标准，可恢复默认；技术输出格式由应用自动处理

### 使用方式

- 详情页“开始 AI 分析”/“重新分析”：单条分析
- “AI 分析本页”：一键分析当前页全部作品，限速执行、实时进度、可随时取消
- 结果按条目缓存；可在详情页手动改为真百 / 轻百 / 非百或恢复跟随 AI。首页仅“非百”显示提示叹号，手动分类显示 `手动·` 徽章
- 高级筛选可按真百 / 轻百 / 非百过滤

## 6. Bangumi 点格子（高级功能）

### 能力

把条目收藏状态写入你的 Bangumi 账号：

- 想看 / 看过 / 在看 / 搁置 / 抛弃

### 单条点格子

- 详情页点格子区域直接点状态写入
- 打开详情页时自动同步一次当前状态
- 列表与封面显示状态徽章（如 `B·看过`）

### 批量点格子

左上角清单图标打开：

- 范围：当前页（20 条）或当前分类全部条目
- 加入列表：想看 / 看过 / 在看 / 搁置 / 抛弃
- 自动跳过已在目标列表的条目
- 自动限速（约 1.2 秒/条），避免触发 Bangumi 频率限制
- 实时进度、可随时取消，完成后显示成功/失败/跳过统计

### 说明

- 需要先在“设置”中配置 Bangumi Access Token
- 官方 v0 接口不提供删除收藏，因此不能“取消收藏”，只能切换五种状态
- 网页端修改状态后，重新打开详情页才会刷新

## 7. 随机推荐

顶栏随机图标：按最低评分随机推荐 5 个条目，可换一组；自动排除屏蔽与屏蔽词命中条目。

## 8. 设置

### 外观

- 跟随系统 / 浅色 / 夜间

### 网络代理

- 跟随系统（推荐）：使用 Android 系统代理或 VPN
- HTTP：适合 Clash、sing-box 等，如 `127.0.0.1:7890`
- SOCKS：地址以 unresolved socket 交给代理

### 数据与隐私

- NSFW 开关：默认关闭；开启后所有 Bangumi 请求携带 Access Token，并请求/展示 NSFW 分区
- 强制重新拉取数据库

### 内容管理

- 屏蔽管理
- 屏蔽词

### 账户与关于

- Bangumi Access Token（可选，用于 NSFW 与点格子）
- 关于：版本、设计、开源说明与百合友链

## 9. 数据与隐私

- Bangumi Access Token 与 AI API Key 使用 Android Keystore 的 AES-GCM 加密保存，不写日志、不进备份
- 不收集账号密码，不读取 Bangumi 评论、日志、讨论
- 所有请求由用户主动触发或按需自动同步

## 10. 已知边界

- `百合` / `轻百合` 是 Bangumi 用户标签，应用只做精确收录，不保证内容判断完全准确
- 官方搜索页大小限制为 20，部分标签查询总数上限 1000，达到上限会提示部分结果
- AI 判断由模型生成，可能出错或存在偏见，结果仅供参考
- 点格子不支持“取消收藏”，且网页端修改后需重新打开详情页刷新
- 当前同步为前台触发与启动时过期检查；后台周期同步暂未实现
- 代理暂不支持用户名/密码认证
